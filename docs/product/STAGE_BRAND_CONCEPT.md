# STAGE 브랜드 콘셉트

버전: v0.1  
작성일: 2026-07-29  
상태: 제품 방향 기준 문서

---

## 1. 서비스명

**STAGE**

STAGE는 춤, 음악, 퍼포먼스 등 무대 위에서 자신을 표현하고 싶은 사람이 함께할 사람과 기회를 발견하고, 실제 무대에 서기까지의 과정을 지원하는 서비스다.

초기 서비스 영역은 댄스이며, 장기적으로는 밴드, 오디션, 공연 프로젝트 등 다양한 무대 활동으로 확장한다.

---

## 2. 슬로건

> **誰もがステージの上で輝けるように。**

한국어 의미:

> **누구라도 스테이지 위에서 빛날 수 있도록.**

이 슬로건은 전문 경력이나 유명세가 없는 일반 사용자도 자신에게 맞는 팀과 기회를 만나 실제 무대 경험을 만들 수 있어야 한다는 STAGE의 기본 철학을 나타낸다.

---

## 3. 해결하려는 문제

춤을 좋아하고 무대에 서보고 싶어도 일반 사용자는 다음과 같은 어려움을 겪는다.

- 함께 무대에 설 사람을 찾기 어렵다.
- 기존 크루는 장기적이고 폐쇄적인 커뮤니티처럼 느껴질 수 있다.
- 참가 가능한 이벤트와 대회를 한곳에서 찾기 어렵다.
- 크루 결성 후 연습 일정, 출결, 스튜디오, 자료를 체계적으로 관리하기 어렵다.
- 프로 댄서나 리더와 일반 사용자가 프로젝트 단위로 만날 수 있는 구조가 부족하다.
- 실력이나 경력이 충분하지 않다고 느껴 무대 도전을 시작하지 못한다.

STAGE는 사용자가 먼저 이벤트나 모집을 발견하고, 개인 단위로 지원해 크루에 합류하며, 연습과 준비를 거쳐 실제 무대에 서는 흐름을 만든다.

---

## 4. 핵심 가치 제안

### 4.1 무대 기회의 발견

사용자는 자신이 참가할 수 있는 이벤트, 대회, 레슨, 워크숍과 크루 모집을 발견한다.

### 4.2 프로젝트형 참여

영구적이고 무거운 커뮤니티 가입보다 특정 이벤트와 기간을 목표로 한 프로젝트형 크루 참여를 우선한다.

### 4.3 개인 단위의 진입

친구와 함께 참가하고 싶은 경우에도 각 사용자가 가입하고 개별 지원한다. 이를 통해 지원, 승인, 출결, 활동 이력을 개인 단위로 관리한다.

### 4.4 준비 과정의 체계화

크루 결성 이후 다음 정보를 한곳에서 관리한다.

- 목표 이벤트
- 연습 일정
- 일정 투표
- 출결
- 공지
- 연습곡과 참고 영상
- 연습 영상 URL
- 스튜디오
- 활동 기록

### 4.5 활동 기록의 축적

한 번의 이벤트가 끝나도 크루와 활동 이력을 보존하고, 다음 목표 이벤트로 이어질 수 있도록 한다.

---

## 5. 초기 타깃

### 5.1 지역

- 일본
- 도쿄 중심
- 스튜디오 데이터는 신주쿠부터 시작

### 5.2 사용자

- 10대부터 30대 여성 중심
- K-POP 댄스에 관심이 있는 일반 사용자
- HIPHOP, 스트리트, 재즈 등 다른 장르 사용자
- 크루에 들어가 무대 경험을 만들고 싶은 사람
- 프로젝트 리더 또는 크루 리더
- 일반 사용자를 모집하고 싶은 프로 댄서와 강사

### 5.3 핵심 초기 사용자

가장 먼저 만족시켜야 하는 사용자는 **크루를 만들려는 리더보다, 자신에게 맞는 크루 모집을 찾고 지원하려는 일반 댄서**다.

---

## 6. 브랜드 포지셔닝

STAGE는 다음 서비스가 아니다.

- 자유 대화를 중심으로 한 범용 SNS
- LINE 그룹 채팅의 대체재
- 프로 댄서만을 위한 폐쇄적 플랫폼
- 영상 업로드와 조회를 중심으로 한 콘텐츠 플랫폼
- 스튜디오 예약 자체가 핵심인 예약 서비스

STAGE는 다음과 같은 서비스다.

> **무대에 서고 싶은 사람이 기회와 사람을 발견하고, 팀을 만들어 준비 과정을 관리하며, 실제 무대 경험을 축적하는 플랫폼**

## 7. 브랜드 원칙

### 7.1 Inclusive

실력, 경력, 인지도와 관계없이 참가 가능한 기회를 보여준다.

### 7.2 Energetic

무대, 퍼포먼스, 도전이 주는 에너지를 시각과 언어에 반영한다.

### 7.3 Encouraging

사용자가 “나는 아직 부족하다”고 느끼기보다 “나도 참가할 수 있다”고 느끼게 한다.

### 7.4 Trustworthy

이벤트 출처, 확인일, 운영자와 리더의 상태, 외부 링크를 명확히 표시한다.

### 7.5 Organized

크루 운영 정보를 찾기 쉽고 구조적으로 보여준다.

### 7.6 Expandable

초기에는 댄스에 집중하되 브랜드와 데이터 구조는 밴드와 다른 무대 활동으로 확장 가능해야 한다.

---

## 8. 톤 앤 매너

### 8.1 언어

- 일본어 UI를 기본으로 한다.
- 짧고 직관적인 표현을 사용한다.
- 초보자에게 위압적이지 않은 문구를 사용한다.
- 지나치게 유아적이거나 가벼운 표현은 피한다.
- 운영·안전 관련 문구는 명확하고 신뢰감 있게 작성한다.

### 8.2 감정

사용자가 느껴야 하는 감정:

- 나도 참여할 수 있을 것 같다.
- 비슷한 사람을 찾을 수 있을 것 같다.
- 다음에 무엇을 해야 하는지 알 수 있다.
- 안전과 운영이 어느 정도 관리되고 있다.
- 실제 무대에 가까워지고 있다는 느낌이 든다.

### 8.3 시각 방향

- 모바일 우선
- 현대적이고 퍼포먼스 지향적인 인상
- 다크 차콜과 퍼플·핑크 계열의 에너지
- 밝은 카드와 명확한 정보 계층
- 둥근 카드와 버튼
- 과도하게 클럽·야간·성인 취향으로 치우치지 않음
- K-POP 친화적이지만 특정 장르 전용처럼 보이지 않음

실제 시각적 source of truth는 `docs/STAGE.html`과 `docs/design/reference/`의 기준 이미지다.

## 9. 핵심 사용자 여정

### 9.1 크루 미소속 사용자

홈  
→ 크루 모집 탐색  
→ 필터  
→ 모집 상세  
→ 개인 지원  
→ 지원 상태 확인  
→ 리더 승인  
→ 크루 합류

### 9.2 크루 소속 사용자

홈  
→ 현재 크루 확인  
→ 다음 연습 확인  
→ 일정 투표·출결 응답  
→ 공지와 연습 자료 확인  
→ 스튜디오 확인  
→ 목표 이벤트 참가  
→ 활동 기록 확인

### 9.3 크루 리더

목표 이벤트 선택  
→ 크루·모집 생성  
→ 지원자 확인  
→ 승인·거절  
→ 멤버 운영  
→ 연습 일정·투표·공지·자료 관리  
→ 이벤트 종료 후 활동 보존  
→ 다음 목표 이벤트 설정

### 9.4 프로 댄서·강사

프로필 설정  
→ 프로·강사 상태 표시  
→ 레슨·워크숍 정보 제공  
→ 프로젝트형 크루 모집  
→ 일반 사용자와 무대 프로젝트 진행

## 10. 장기 확장 방향

- 밴드 멤버 모집과 공연 프로젝트
- 자체 이벤트와 쇼케이스
- 오디션과 엔터테인먼트 회사 제휴
- 이벤트 참가비와 티켓 판매
- 티켓 할당과 정산
- 프로 댄서 레슨 예약과 수수료
- 스튜디오 광고와 송객 수수료
- 댄스 의상·굿즈 제휴
- 공연용 메이크업·의상 파트너십
- 크루 운영용 프리미엄 멤버십

장기 확장은 초기 MVP의 사용자 경험을 복잡하게 만들지 않는 범위에서 단계적으로 진행한다.

---

## 11. 브랜드 의사결정 기준

새로운 화면이나 기능을 검토할 때 다음 질문을 사용한다.

1. 이 기능은 사용자가 실제 무대에 가까워지도록 돕는가?
2. 일반 사용자의 진입 장벽을 낮추는가?
3. 크루 운영을 더 명확하게 만드는가?
4. 안전성과 신뢰성을 약화하지 않는가?
5. LINE이나 범용 SNS와 중복되는 기능을 과도하게 만들지 않는가?
6. 댄스에 적합하면서도 미래 확장을 막지 않는가?
7. 모바일 화면에서 핵심 행동을 쉽게 이해할 수 있는가?
